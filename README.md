Sitio estático para GitHub Pages en https://elias0902.github.io/

## Antes de publicar
1. Tu número en main.js (constante WHATSAPP): 58 + operadora sin 0 + número. Ej: 584141234567
2. Tu retrato en img/elias.jpg (vertical, 4:5)
3. Revisa que la captura img/natys-dashboard.png no muestre datos reales de clientes

## Publicar
git init && git add . && git commit -m "Landing" && git branch -M main
git remote add origin https://github.com/Elias0902/Elias0902.github.io.git
git push -u origin main
Luego: Settings → Pages → Deploy from a branch → main / (root)
